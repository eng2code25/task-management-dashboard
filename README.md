Task Management Dashboard (React)

## What this does

A task management dashboard built with React to practice real-world frontend development concepts beyond basic CRUD operations.

The application allows users to create, edit, delete, search, filter, and manage tasks while persisting data locally. It also includes API integration through a live weather widget to simulate working with external services.

## Features

### Task Management

* Create tasks
* Edit existing tasks
* Delete tasks
* Assign task status (Not Complete, In Progress, Complete)
* Set task priority
* Add due dates

### Search & Filtering

* Search tasks dynamically
* Filter by task status
* Filter by task priority

### Dashboard & UI States

* Task statistics summary
* Overdue task highlighting
* Responsive card layout
* Dynamic UI updates using React state

### Persistence

* Save tasks using localStorage
* Automatically restore tasks on page refresh

### API Integration

* Weather dashboard using external weather API
* Country and capital city selection using REST Countries API
* Dynamic weather updates based on selected location
* Hide/show weather widget functionality

## Notes

This project was designed to move beyond a simple notes application and simulate how software evolves over time through feature requests and changing requirements.

Instead of building a new project each time, I incrementally added functionality such as task filtering, overdue detection, dashboard statistics, and API integration. This helped me practice maintaining and extending an existing codebase while improving my React fluency.
